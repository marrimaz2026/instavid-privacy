# instavid-privacy

Official Privacy Policy for InstaVid, published with GitHub Pages:
https://marrimaz2026.github.io/instavid-privacy/

This is the only copy of the policy. The extension's "Privacy policy" link and the Chrome Web Store / Edge Add-ons listings all point to this page, so update the policy here (`index.html`) and nowhere else.

When the policy changes, update the effective date and version at the top of `index.html`.
